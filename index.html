      MINERAL OPTICAL-PROPERTY REFERENCE

      Approximate visible-light refractive-index values around 589 nm; anisotropic crystals show two principal indices and real values vary with composition, temperature, and wavelength. These are laboratory mineral properties—not values measured by VIIRS or inferred for an MRDS site.

      MineralFormulaIndicative RI at visible wavelengthsOptical / space-data note

      Metallic ore minerals (e.g., native gold, platinum, many copper and iron ores) are opaque: a single real RI is unsuitable; spectroscopy uses wavelength-dependent complex n + ik. Bauxite and rare-earth ores are mineral mixtures, so there is no single commodity RI. Visible VIIRS true-colour imagery does not resolve mineral RI. Surface mineral mapping uses calibrated multispectral data such as NASA ASTER (14 bands) or airborne hyperspectral data such as NASA AVIRIS, then field/laboratory confirmation.

      Optical-data references: Ghosh (1999), calcite and quartz dispersion; RefractiveIndex.INFO database. Values are for mineral-species context only.
